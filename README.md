Investigation of the Previous Manual Library Management System
Wayamba University of Sri Lanka
This repository contains the documentation prepared for the study of the previous manual library management system used at the Wayamba University of Sri Lanka before the introduction of the Koha online library system.
The study focuses on how the traditional paper-based system managed library users, books, borrowing and returning activities, cataloguing, stock verification, fines, inter-university loans, lost books, library clearance, and physical library records.

- Full Report: [Study of the Traditional Physical Library Card System Used at Wayamba University of Sri Lanka](./Study of the Traditional Physical Library Card System Used at Wayamba University of Sri Lanka.pdf)
Main Topics
- Library user types and member registration
- Book information and identification
- Book pockets and book cards
- Manual book borrowing and returning
- Due-date marking
- Manual card catalogue system
- Fines and late returns
- Inter-University Loan (IUL) system
- Annual stock verification
- Damaged and lost books
- Student and staff library clearance
- Registers and record books
- Transition from the manual system to the computerized system
